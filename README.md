## Roseate VS Code theme

A dark theme which utilizes shades of pink and a tiny bit of spring green.  
Aimed to make my C++ code prettier; or, really, just so it goes well with all the *wild cherry* Pepsi that's seemingly always there next to my computer.

![Preview](preview.png)

---

### Editing the theme

`themes/Roseate-color-theme.json` is generated. Colors are named in `src/palette.mjs`, `src/color.mjs` has the `alpha()` and `over()` modifiers, and `src/colors.mjs` and `src/tokens.mjs` map them onto UI and syntax. After editing, run `npm run build`.
